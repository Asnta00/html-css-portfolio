Привіт, я Божик Анастасія

Студентка спеціальності «Інформаційно-вимірювальні технології». Вивчаю сучасні вимірювальні технології, програмування та методи обробки вимірюваних даних.

Переглянути мої роботи

Про мене

Я студентка 2 курсу Чернівецького національного університету імені Юрія Федьковича. Родом із села Мигово, Чернівецької області. У вільний час люблю займатися спортом, читати книги та постійно вдосконалювати свої навички у професійній сфері. Обрала цю спеціальність, оскільки мене цікавлять сучасні технології, робота із вимірювальними приладами та точні науки.

Під час навчання на першому курсі я вивчала мову програмування Python. Також опановувала LabVIEW, де виконувала лабораторні роботи з підключенням і обробкою даних з вимірювальних датчиків. Крім того, працювала в MATLAB, використовуючи його для математичних розрахунків, моделювання та візуалізації результатів. Наразі вивчаю HTML і CSS для створення сучасних вебсайтів

Моя мета — стати кваліфікованою фахівчинею у сфері інформаційно-вимірювальних технологій, поглиблювати знання в програмуванні та аналізі даних, а також застосовувати сучасні технології для розробки ефективних програмних рішень і автоматизованих систем вимірювання та контролю.

Навички

  • HTML — структура вебсторінок
  • CSS — стилізація сторінок
  • LabVIEW — програмне забезпечення для розробки вимірювальних систем
  • MatLab — система програмування та обчислювальної техніки
  • Python — мова програмування для аналізу даних

Мої проєкти

Аналіз експериментальних даних

У цьому проєкті я виконувала обробку експериментальних даних за допомогою Python. Будувала графіки, гістограми та проводила статистичний аналіз отриманих результатів. Це дозволило наочно представити дані та зробити відповідні висновки.

Переглянути

Віртуальні прилади в LabVIEW

В даному проєкті я створювала віртуальні прилади в LabVIEW для роботи з вимірювальними датчиками. Виконувала збір, обробку та візуалізацію отриманих даних у вигляді графіків та індикаторів на фронтальній панелі. Це дало змогу ознайомитися з принципами автоматизації вимірювань.

Переглянути

Туристичний вебсайт «Мигове»

Цей проєкт про створення інформаційного вебсайту про гірськолижний курорт Мигове. На сайті розмістила інформацію про активний відпочинок, визначні місця, варіанти проживання та сезонні розваги. Для розробки використала HTML і CSS.
